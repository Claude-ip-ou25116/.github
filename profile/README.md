<p>被机房线路坑过一次的人，第二次采购通常会走向另一个极端：一口气买五十条，结果发现一半不能用。更省事的做法是把"实测"拆成四层，每层有明确的通过标准和淘汰线，先领三条跑一遍，通过率为七成以上再谈批量。这篇把四层拆开讲，并给一张四层汇总的判定表，照着填就能给自己一个结论。</p>

<h2>一、实测拆四层，别一上来就批量</h2>
<p>四层是：连通层、归属层、纯净层、行为层。顺序不能乱，因为后一层依赖前一层的结果。连通不过，谈归属没意义；归属不对，谈纯净没意义。</p>
<p>每层的成本不同：连通层十分钟，归属层二十分钟，纯净层要问供应商，行为层要跑两天。所以整体节奏是：先快后慢，前两层当天出结论，后两层跑满两天再定。</p>
<h3>为什么先领三条而不是一条</h3>
<p>一条线路的表现无法区分"这条线有问题"和"这批货都有问题"。三条是能看出趋势的最小样本，成本也不高。三条里坏两条，基本可以判断是货源问题而不是运气。</p>
<h3>四层的淘汰线怎么定</h3>
<p>连通层：十次请求成功少于九次淘汰。归属层：ASN 是机房或城市不符淘汰。纯净层：近三个月被多个号轮换使用淘汰。行为层：晚间九十分位超过五秒淘汰。四条线都是硬线，不留模糊空间。</p>

<h2>二、第一层连通：先证能通，再谈好坏</h2>
<p>连通层只回答一个问题：这条线能不能稳定地把请求送出去。不看速度，只看成功率和稳定性。</p>
<p>做法是连续十次请求，记录每次的耗时和状态码。全通且耗时波动不大，通过；有两次以上失败，淘汰；全通但耗时波动超过三倍，记下来交给第四层判断。</p>
<h3>握手和传输要分开测</h3>
<p>握手快、传输慢，说明链路没问题但带宽被限；握手就慢，说明路径远或上游拥塞。两种情况的处置不同，前者换套餐，后者换节点。混在一起测，只看总耗时是分不出来的。</p>
<h3>本地干扰要先排除</h3>
<p>测之前先直连跑一次同样的请求，作为基线。如果直连本身就抖，测出来的数据没有参考价值。这一步两分钟，能省掉后面一堆误判。</p>

<h2>三、第二层归属：城市、ASN、路由记录</h2>
<p>归属层是机房线路最容易翻车的地方。有些地址查询显示在某个城市，ASN 却指向数据中心，这种"看着像家宽"的地址，用起来和机房段没区别。</p>
<p>查三样：注册城市、ASN 机构名、路由跳数与路径。三样都要留截图，作为后续维权的依据。截图带时间戳，比任何口头承诺都有效。</p>

<h3>ASN 机构名怎么读</h3>
<p>家宽 ASN 的机构名通常是电信运营商，机房 ASN 会指向数据中心或云服务商。不用记编号，认机构名的性质就够。名字看着陌生就再查一次，别凭感觉。</p>
<h3>路由跳数能看出什么</h3>
<p>跳数异常少或异常多都值得注意。太少可能是同城直连的机房中转，太多说明路径绕行严重，延迟会不稳定。正常家宽到主要目标的跳数通常在十到二十之间。</p>

<h2>四、第三层纯净：复用率与历史痕迹</h2>
<p>纯净层是唯一自己测不出来的一层，只能问。要两样数据：近三个月这个地址被多少个账号使用过，以及这段时间内是否有异常记录。</p>
<p>要不到具体数字时，用两个替代指标：池子规模和分配策略。池子是活跃号数的二十倍以上、按城市分散分配、同一地址短期不重复分配的，复用率通常可控。</p>
<h3>为什么问三个月而不是问"干不干净"</h3>
<p>"干不干净"是主观判断，谁都会说干净。三个月内的占用数是可验证的客观事实，即使对方给的数字有水分，也比一句形容词有信息量。</p>
<h3>新地址的第一周要克制</h3>
<p>新地址的洁净度是有时效的。刚拿到就跑高频任务，行为特征会迅速偏离家庭用户，等于自己把干净的地址用脏。第一周按正常强度跑，别一上来就压满。</p>

<h2>五、第四层行为：并发、长连接、时段表现</h2>
<p>行为层要跑两天，覆盖三个时段：上午、晚间、凌晨。这层看三件事：同时在线几个号会互相挤、长连接能撑多久、晚间延迟涨多少。</p>
<p>并发测试从一号开始，逐小时加一个，直到出现挤占为止，把那个数字减一就是这条线的可用并发。长连接测试挂一个会话，记录断开间隔。晚间测试与前两项分开做，避免互相干扰。</p>
<h3>四层汇总怎么判</h3>
<p>四层全部通过，可以批量；有一层存疑，先扩大样本到五条再定；有一层淘汰，换货源，别在存疑的线上批量下单。三条里通过两条以上，可以谈批量但要求分批交付。</p>
<h3>分批交付是为了留退路</h3>
<p>五十条一次交付，发现问题时已经付了全款。分三批、每批间隔三天，第一批验完再要第二批，出问题的损失控制在一批之内。这个要求多数供应商能接受。</p>

<h2>常见问答</h2>
<h3>三条都通过，可以直接上五十条吗？</h3>
<p>答：不建议一次上满。先上十条跑三天，再上二十条，最后补齐。中间任何一批出问题，都能停下来定位，而不是五十条一起排查。</p>
<h3>归属层查出来是小型接入商，能用吗？</h3>
<p>答：可以先做行为层测试。小型接入商的地址属性介于家宽和机房之间，实际表现要看路由。行为层能过就用，过不了就换。</p>
<h3>供应商不给三个月占用数据怎么办？</h3>
<p>答：看它能不能给池子规模和分配策略。两样都说不清的，按存疑处理，先小批量试用，别签长约。</p>
<h3>实测通过后，多久要复测一次？</h3>
<p>答：新线每月复测一次归属，行为层每季度一次。线路本身变化不大，但地址的使用情况会变，复测主要是看有没有被别人用过。</p>

<h2>合规提示</h2>
<p>本文为网络出口质量的分层实测方法说明，所列标准与耗时为经验参考，不构成对任何服务商或产品的推荐。</p>
<p>先领几条实测是稳妥做法，但实测内容应限于连通性、延迟、归属地这些客观指标。用实测去试探平台风控阈值的做法既违反服务条款，也容易让整批账号一起受影响。</p>
<p>实测数据仅反映测试时段的表现，请结合自身业务规模与使用时段综合判断。</p>
